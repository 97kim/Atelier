# Atelier

**Claude Code와 Codex를 탭으로 띄워 함께 일하는 macOS 앱이에요.**

한쪽에 고치게 하고 다른 쪽에 리뷰를 맡기거나, 같은 일을 동시에 시켜 결과를 비교할 수 있어요.
코드 편집, git 커밋, 터미널, 브라우저까지 앱 안에서 끝나요.

![Claude가 장바구니 버그를 고치다가 명령 실행 권한을 묻는 화면](docs/images/hero.png)

모든 건 내 Mac에서 돌아요. 서버도 계정도 텔레메트리도 없이, 이미 로그인해 둔 `claude`·`codex` CLI를 앱이 찾아서 써요.

## 설치

```
brew tap 97kim/atelier
brew trust 97kim/atelier
brew install --cask atelier
```

새 버전은 `brew upgrade --cask atelier`로 받으면 돼요. Homebrew 7부터는 새로 추가한 탭을 `brew trust`로 한 번 신뢰해야 설치할 수 있어요.
[Releases](https://github.com/97kim/Atelier/releases)에서 DMG를 받아 `Atelier.app`을 Applications 폴더로 옮겨도 돼요.

서명과 공증을 하지 않은 앱이라 처음 열 때 macOS가 막아요. **시스템 설정 → 개인정보 보호 및 보안**에서 "그래도 열기"를 누르거나, 터미널에서 격리 표시를 떼세요.

```
xattr -d com.apple.quarantine /Applications/Atelier.app
```

**필요한 것**: Apple Silicon Mac, 그리고 로그인을 마친 `claude` 또는 `codex` CLI.

## 무엇을 할 수 있나요

### 두 에이전트를 한 화면에서

- **탭마다 Claude Code나 Codex를 골라요.** 대화 도중에 바꾸면 지금까지의 내용을 요약해서 넘겨줘요.
- **화면을 좌우로 나눠** 두 탭을 나란히 보고, ⌘⌥←/→로 오가요.
- **교차 리뷰**: 한쪽이 바꾼 코드를 다른 쪽 새 탭에 보내 독립적인 리뷰를 받아요.
- **팬아웃**: 같은 지시를 여러 격리 세션에 동시에 보내고, 결과 diff를 비교해 마음에 드는 것만 가져와요.

![왼쪽은 Claude가 버그를 고친 diff, 오른쪽은 Codex가 같은 코드를 리뷰한 분할 화면](docs/images/split.png)

### 안심하고 맡기기

- **권한 카드**: 파일을 바꾸거나 명령을 실행하기 전에 무엇을 하려는지 보여 주고 물어봐요. "변경 전 물어보기", "편집 자동 승인", "전부 자동" 중에서 골라요.
- **격리 세션**: 탭마다 git worktree로 브랜치와 작업 폴더를 따로 줘서, 같은 저장소에서 여러 세션이 서로의 파일을 덮어쓰지 않아요.
- **변경 리뷰와 커밋**: 바뀐 파일을 diff로 보고 되돌리거나, 커밋 메시지 초안을 받아 앱 안에서 바로 커밋해요.
- **검증 버튼**: 테스트·빌드 명령을 저장해 두고 한 번에 돌려요. 결과가 대화에 카드로 남아서, 실패하면 그대로 "이거 고쳐 줘"라고 이어 갈 수 있어요.
- **여기서 분기**: 끝난 턴에서 대화를 새 탭으로 갈라, 원래 대화는 그대로 둔 채 다른 방향을 시도해요.

### 코드·터미널·브라우저를 앱 안에서

- **코드 에디터**: 파일 트리에서 열어 고치고 저장해요. TypeScript·Python은 자동완성과 정의로 이동을 지원해요. 답변 속 파일 이름을 누르면 그 줄로 바로 열려요.
- **터미널**: 채팅 아래나 오른쪽에 열고 좌우·상하로 나눠요. 같은 대화를 터미널의 CLI에서 이어 갈 수도 있어요.
- **앱 안 브라우저**: 개발 중인 화면을 바로 띄워요. 폰·태블릿 폭으로 바꿔 보고, 앱을 껐다 켜도 로그인이 유지돼요. 에디터에서 연 HTML 파일도 여기서 미리 봐요.
- **에이전트가 브라우저를 직접 확인**: `atelier browser` 명령으로 에이전트가 페이지 글을 읽고 버튼을 눌러 보며 스스로 확인해요.
- **넓게 보기**: ⌘⇧E로 에디터나 브라우저를 창 전체로 키워요. 채팅의 스크롤과 쓰던 글은 그대로 남아요.

![채팅에는 Claude가 고친 diff, 오른쪽 터미널에는 테스트 통과 결과](docs/images/terminal.png)

### 손이 덜 가게

- **대기열**: 작업 중에 다음 지시를 써 두면 끝난 뒤에 보내요. Codex에는 "지금 반영"으로 진행 중인 작업에 바로 끼워 넣을 수 있어요.
- **예약**: 매시·매일·평일·매주, 또는 cron으로 정한 시각에 새 세션을 열어 프롬프트를 보내요. 회차마다 완료·실패·승인 대기, 건너뛴 이유까지 남아요. 앱이 켜져 있을 때 돌아요.
- **슬래시 커맨드와 스니펫**: `/`를 치면 Claude의 커맨드·스킬이 뜨고, 자주 쓰는 지시문은 스니펫으로 저장해 `/이름`으로 꺼내요.
- **응답이 필요한 세션 알림**: 권한을 기다리거나 끝난 세션을 사이드바와 Dock 배지, macOS 알림으로 알려 주고, ⌘⇧↓로 바로 찾아가요.
- **대화 검색과 내보내기**: ⌘F로 닫은 세션까지 모든 대화와 도구 호출을 찾고, 대화를 마크다운 파일로 내보내요.
- **백그라운드 작업 표시**: 턴이 끝난 뒤에도 돌고 있는 작업을 대화 아래에 보여 주고, 끝나면 알려 줘요.

### 비용과 한도를 한눈에

- 모델·워크스페이스별 사용량과 비용, Claude·Codex 구독 한도를 보여 줘요.
- 컨텍스트 창이 차면 미리 알려 주고, Claude 사용 한도에 걸리면 풀리는 시각에 자동으로 다시 시도해요.

### 밖에서 조종하기

- `atelier` CLI로 탭을 만들고, 지시를 보내고, 답을 읽어요. 에이전트가 다른 에이전트에게 일을 나눠 맡기는 오케스트레이션도 이 위에서 돌아가요.

그 밖에 다크 모드, 이미지 붙여넣기도 돼요.

## 자주 쓰는 단축키

| 단축키 | 하는 일 |
|---|---|
| ⌘T | 새 세션 |
| ⌘1~9 | 탭 이동 |
| ⌘J | 터미널 열고 닫기 |
| ⌘F | 대화 검색 |
| ⌘⇧E | 에디터·브라우저 넓게 보기 |
| ⌘K | 워크스페이스 전환 |
| ⌘⌥← / ⌘⌥→ | 분할 화면에서 옆 칸으로 |
| ⌘⇧↓ / ⌘⇧↑ | 답을 기다리는 세션으로 |

## 자주 묻는 질문

### 계정이나 API 키가 필요한가요?

아니요. 각자 로그인해 둔 `claude`·`codex` CLI를 그대로 써요. 요금도 각 서비스의 구독이나 API 요금 그대로예요.

### 내 코드가 어디로 가나요?

Atelier 자체는 아무 데도 보내지 않아요. 모델과의 통신은 Claude Code·Codex CLI가 평소처럼 해요.

### 데이터는 어디에 저장되나요?

워크스페이스와 채팅 기록은 `~/Library/Application Support/Atelier/`에, 격리 세션의 worktree는 `~/atelier/worktrees/`에 있어요. **설정 → 일반 → 저장 위치**에서 열거나 바꿀 수 있어요.

### Intel Mac에서도 되나요?

지금은 Apple Silicon만 지원해요.

## 라이선스

소스 코드는 누구나 볼 수 있게 공개했지만, 오픈소스 라이선스를 붙이지 않았어요. 모든 권리는 97kim에게 있어요.
GitHub 이용 약관이 허락하는 범위(GitHub 안에서 보기·포크) 말고는, 허락 없이 코드를 복제하거나 고쳐서 배포할 수 없어요.
앱은 [Releases](https://github.com/97kim/Atelier/releases)나 Homebrew로 받아 자유롭게 쓰면 돼요.
